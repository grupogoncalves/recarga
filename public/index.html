Área de importação de dados

Ferramenta de teste local para cadastrar clientes e importar arquivos CSV. Não publicar esta área com dados reais sem autenticação e backend seguro. Os dados ficam somente neste navegador. A área de teste deve ser removida ou protegida antes da publicação.

Importar histórico CSV

Aceita o CSV original da Spott Eco (Data, E-mail do motorista, Energia, Recargas etc.) ou o formato simplificado cliente_id,data,estacao,kwh. O arquivo original deve ser carregado apenas no painel administrativo privado. Colunas do modelo simplificado: Data no formato AAAA-MM-DD HH:MM, kWh com ponto decimal. Exemplo: cliente001,2026-10-05 16:30,Estação Centro,25.4. Clientes devem estar cadastrados antes da importação.

Consulta de teste local: não equivale ao acesso autenticado do cliente.
